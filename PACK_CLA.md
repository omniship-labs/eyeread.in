## 13. How to sign

The packs repo, `omniship-labs/eyeread.in-packs`, uses
**[CLA Assistant](https://cla-assistant.io)** to manage signatures. When you
open a pull request there, the bot checks whether you have signed the Pack CLA.
If not, it posts a status check with a link to sign. Signing takes one click
via GitHub OAuth. Your GitHub username and the date of signing are recorded in
a private Gist managed by CLA Assistant. Review starts once you've signed.

The canonical Pack CLA document will be hosted in a Gist linked here once the
packs repo is set up.

**Corporate authors:** if you submit on behalf of a company, open an issue so
we can arrange a corporate Pack CLA before your first submission.
